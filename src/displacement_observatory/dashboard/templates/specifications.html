Every estimator tried against every testable treatment package, in the order they were built during the causal-specification repair. This page exists because the ORIGINAL Stage 3 numbers on the Ranked Findings page were found to be uninformative — the wrong estimator, the wrong comparison group, and an inflated event count — and re-running the same analysis with a better specification changes the answer, sometimes sharply.
